# Freelance Studio

Minimalist freelance digital studio website.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `app/page.tsx` for your:
- Brand name
- Services
- Portfolio projects
- Pricing
- Email/social links

Edit `app/globals.css` for colors and typography.

Main background: `#F5F5DC`
